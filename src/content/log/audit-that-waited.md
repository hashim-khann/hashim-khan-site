## What happened

I audited the indexing issues on the old site and documented 12 fixes for developers. Because a new site was being built, the fixes were parked. Four months later the same report showed almost all the same issues.

## What I took from it

- Fixes that won't be done still need a written decision, so the question doesn't come back later
- An audit for an old site is still useful: it becomes the checklist for the new one
- Separate the issues by whether the new site will carry them over
