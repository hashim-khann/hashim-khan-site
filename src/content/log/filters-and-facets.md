## The problem

Every filter combination can create a new URL. Most of them shouldn't be in search results, but a few match real searches and deserve their own page.

## How I think about it

- Index a filtered page only if people actually search for it ("black running t-shirts")
- Give those pages proper titles, copy and links, like real category pages
- Keep the rest out of the index, and don't link to them in ways that waste crawling
- Decide the filter order based on how shoppers choose, not how the catalogue is stored
