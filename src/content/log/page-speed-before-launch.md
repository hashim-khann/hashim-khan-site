## What we checked

- Page weight, and which files make up most of it
- Images and icons served larger than they're shown
- CSS and JavaScript that block the page from rendering
- How the main image loads, and whether it is prioritised
- Desktop and mobile separately, because the problems were different

## What I learned

The biggest wins were not where the speed tools first pointed. Testing each page type, on each device, before deciding what to fix saved a lot of wasted effort.
